# CIFAR-10 airplane and ship GAN

Conditional DCGAN trained on the CIFAR-10 airplane and ship classes. It
generates RGB 32×32 images from a random vector and a class label.

The discriminator is used during training only. The PNG contains the trained
generator weights and BatchNorm statistics. The browser runs that generator
directly without image filters or other post-processing.

## Train

From the repository root:

```bash
cd examples/cifar10/train
python train.py
```

The default is 20 epochs with a batch size of 64. CPU training uses the number
of cores reported by Python; set `--cpu-threads` to override it. This shorter
run is intended to keep the example manageable; it does not guarantee realistic
images. Increase `--epochs` or use a CUDA GPU for longer training runs.

## Export

Run from `examples/cifar10/train`:

```bash
python export_float32.py --checkpoint checkpoints/airplane_ship_gan/airplane_ship_gan_final.pt
python export_int8.py --checkpoint checkpoints/airplane_ship_gan/airplane_ship_gan_final.pt
```

## Demo

Open `web/index.html`, load one of the exported PNGs, choose Airplane or Ship,
and generate.

## How generation works

Training teaches a neural network to generate 32×32 RGB images from a random
input and a class label. The exported PNG stores the generator weights and
normalization statistics. In the browser, JavaScript runs the network's forward
pass and sends its RGB output directly to the canvas. It does not apply image
filters, add details, or clean up the result.

The exported files in this folder are named `cifar10_float32.png` and
`cifar10_int8.png`. They are the RGB Airplane/Ship GAN models generated by the
commands above. Training can still produce imperfect images; more epochs do not
guarantee photorealism, and the output is intentionally simple and honest.

## Notes

- Output size: 32×32 RGB
- Classes: 0 = airplane, 1 = ship
- Same TensorRGBA format and pure JS decoder as the MNIST example
